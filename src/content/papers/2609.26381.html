01Problem · parser

PDF에서 본문·그림·표·머리말을 같은 모델에 맡기면 구조가 깨진다

한눈에 요약

GROBID는 font-stream token을 cascade 모델로 분류합니다. 논문은 detector가 figure/table/paratext를 먼저 찾아 fulltext 모델의 오판을 줄입니다.

기여는 OCR/recognizer를 새로 만드는 것이 아니라, 기존 parser에 어느 token을 어느 모델로 보낼지 알려주는 routing입니다.

생활 속 비유 · 작은 예 · 논문 대응

비유: 도서관에서 책 본문·사진·표·페이지 번호를 먼저 다른 바구니에 분류한 뒤 각 담당자에게 보내는 것입니다. 작은 예: 표 안 글자를 문단으로 읽지 않고 table model로 보냅니다. 논문 대응: typed-area masking은 parser의 모델 dispatch만 바꾸고 TEI schema와 전용 모델은 유지합니다.

02Evaluation · protocol

JATS를 기준으로 텍스트·구조·표·그림을 분리해 비교한다

한눈에 요약

PMC Bioinformatics 1,926개와 Materials Science 2,595개, 합계 4,521개 논문을 JATS ground truth와 paired 비교했습니다.

NS/WER/CER, section F1·순서·paragraph precision/recall, table F1·GriTS·TEDS, figure recovery를 분리해 계산하고, paired Wilcoxon/Holm correction과 perturbation validation을 사용했습니다.

03Results · routing

masking은 특히 표 경계를 바로잡고 본문 precision을 높인다

한눈에 요약

Bioinformatics에서 plain 대비 NS +0.025, Materials에서 +0.013, Materials paragraph recall +0.086, effect size dz=1.08을 보고합니다.

Table-BRGM F1은 0.16→0.94, GriTS-Top 0.27→0.78로 크게 개선됩니다. 표 모델 자체는 바꾸지 않고 bounding region만 바로 잡은 효과입니다.

04Results · Docling

Docling은 표의 일부 점수와 시각적 단어 경계를 앞서지만 비용·구조 precision은 trade-off다

한눈에 요약

GROBID+PP는 두 corpus에서 paragraph precision이 0.885/0.901로 최고였고 Materials section detection도 최고였습니다.

Docling은 PubTables/ICDAR의 table TEDS와 detection에서 더 높지만, Bioinformatics paragraph precision은 0.685이고 CPU 비용은 GROBID+PP보다 문서당 6–10배, $/million 7–11배 높다고 측정됩니다.

05Deployment · 결론

CPU 대규모 수집에는 hybrid routing이 매력적이지만 입력·비용 범위를 먼저 확인한다

한눈에 요약

CPU GROBID+PP는 detector 포함 비용이 generative parser보다 10–14배 낮고, Docling GPU보다 2.7–3.2배 낮다고 측정됩니다. CPU Docling은 GROBID+PP보다 6–10배 느리고 $/million 7–11배 비쌉니다.

OmniDocBench scientific subset에서도 table TEDS 31.5→54.7, structure-only TEDS 36.5→63.5, emitted tables 46→75로 mask 효과를 재현했습니다.
