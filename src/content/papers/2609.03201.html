01Background · 배경

장기 메모리는 ‘비슷한 문장 찾기’만으로 부족하다

한눈에 요약

에이전트가 오랫동안 대화하면 같은 사실의 반복, 값의 변경, 서로 모순되는 주장, 과거 상태가 함께 쌓인다. 의미상 가까운 문장만 검색하면 최신값과 폐기된 값을 구분하기 어렵다.

예를 들어 사용자가 “나는 서울에 산다”라고 했다가 나중에 “부산으로 이사했다”고 말하면, 두 문장은 모두 관련 있지만 현재 답은 하나다.

기존 텍스트 메모리는 보통 각 항목을 독립 벡터로 저장한다. 반대로 거대한 지식 그래프를 매번 재구성하면 비용과 오류 전파가 커진다. MemoryLACE는 그 중간에서, 원문 메모리는 그대로 두고 꼭 필요한 생애주기 관계만 희소 그래프로 연결한다.

02Lifecycle · 쓰기 단계

새 기억 하나를 가까운 후보와만 비교해 관계를 붙인다

한눈에 요약

각 메모리는 출처가 보존된 원자적 자연어 문장이다. 새 항목은 제한된 후보 집합과 비교되어 merge·supersession·contradiction·no action 중 하나의 관계를 얻는다.

merge는 같은 증거의 중복, supersession은 이전 상태를 대체하는 업데이트, contradiction은 같은 범위의 양립 불가능한 주장이다.

대체된 기억은 지우지 않고 비활성 상태로 남긴다. 덕분에 “예전에는 어디에 살았나” 같은 질문에도 답할 수 있고, 답의 출처도 추적할 수 있다. 여러 후보를 한 번에 복잡하게 판정하지 않고 한 결정씩 처리한 뒤, 작은 로컬 배치에서 빠진 관계를 보완한다.

03Retrieval · 읽기 단계

현재 기억을 먼저 찾고, 그 기억의 과거와 충돌 근거를 따라간다

한눈에 요약

질의 시 의미·키워드·구조 템플릿·주제 검색 결과를 RRF로 합친다. 먼저 활성 기억만 앵커로 찾고, 이후 생애주기 간선을 따라 과거 버전과 모순 증거를 확장한다.

검색 결과는 개별 문장 묶음이 아니라 서로 관련된 evidence unit으로 만들어 재순위화된다.

이 순서는 중요하다. 처음부터 모든 과거 기억을 같은 후보 풀에 넣으면 폐기된 정보가 현재 답을 밀어낼 수 있다. MemoryLACE는 현재 상태를 중심으로 찾은 뒤 필요한 경우에만 이전·모순 증거를 붙여, 최신성 질문과 변화 추적 질문을 모두 지원한다.

04Evidence · 실험 결과

같은 백본끼리 비교해 평균 성능과 처리시간에서 이득을 보였다

한눈에 요약

BEAM 100K 부분집합에서 Qwen3.5-9B MemoryLACE의 종합 점수는 51.9로 Hindsight 50.3, LIGHT 42.1, SimpleMem 30.7보다 높았다. 전체 처리시간은 22시간 30분에서 7시간 31분으로 줄어 2.99배 빨랐다.

평가는 20개 대화와 400개 질문으로 구성된 BEAM 100K 부분집합, 그리고 51개 시나리오의 StructMemEval을 사용했다.

GPT-5.5를 백본으로 쓴 StructMemEval에서 상태 추적 14개와 트리 과제 10개는 모두 해결해 각각 100%를 기록했고, 매크로 평균은 Mem-Agent 35.0에서 52.08로 올랐다. 그러나 카운팅은 두 시스템 모두 0%, 추천 시나리오는 MemoryLACE가 8.33%로 더 낮았다. 평균 상승이 모든 메모리 능력의 해결을 뜻하지 않는다.

05Ablation & Limits · 한계

핵심 이득은 관계를 저장하는 것보다 검색 때 다시 펼치는 데서 컸다

한눈에 요약

생애주기 확장을 제거하면 종합 점수가 51.9에서 46.7로 5.16점 떨어졌고, 시간 인식을 제거하면 46.9로 4.97점 떨어졌다. 모든 주요 요소를 함께 빼면 43.3이었다.

즉, 그래프를 만들기만 해서는 부족하고 질문 시점에 현재 기억의 과거·충돌 관계를 실제 컨텍스트로 되살리는 과정이 중요하다.

한편 실험 범위는 BEAM의 20개 대화와 합성 구조 과제 51개로 작고, 일부 평가는 LLM 판정기에 의존한다. 논문에는 독립적인 인간 평가나 장기간 실제 사용자 배포가 없다. 카운팅 실패와 낮은 추천 성능은 희소 관계 그래프만으로 집계·선호 모델링까지 해결되지는 않음을 보여준다.

가장 중요한 경계

MemoryLACE는 모든 사실을 정규화한 포괄적 지식 그래프가 아니다. 원문 텍스트를 보존하면서 변경·병합·모순 관계만 국소적으로 연결한 메모리 구조다.

＋Glossary · 핵심 용어

핵심 용어 정리

한눈에 요약

논문의 주장을 따라가는 데 필요한 용어만 간결하게 모았다.

원자적 기억Atomic memory

한 가지 사실이나 사건을 담고 원래 출처를 가리키는 작은 자연어 단위.

활성 기억Active memory

현재 상태를 나타내어 1차 검색 대상이 되는 기억.

대체 관계Supersession

새 기억이 같은 속성의 더 이전 상태를 대신한다는 방향 관계.

모순 관계Contradiction

같은 범위에서 동시에 참일 수 없는 두 증거의 연결.

RRFReciprocal Rank Fusion

서로 다른 검색기의 순위들을 순위 역수 점수로 합치는 방식.

증거 단위Evidence unit

현재·과거·모순처럼 함께 읽어야 의미가 완성되는 기억 묶음.
