01Audit · 감사

벤치마크 감사의 질문

한눈에 요약

SWE-bench Verified는 500개 실제 GitHub issue에서 패치를 실행한다. 이 논문은 모델을 재실행하지 않고 254개 공개 제출의 문항별 verdict를 분석해 표시된 순위가 분리되는지 묻는다.

상위 두 시스템은 각각 396/500을 해결했고 상위 10개는 285개를 모두 해결하고 51개를 모두 실패했다. 전체 점수보다 서로 다른 결과를 만드는 문항이 비교의 핵심이다.

02Resolution · 분리능

공통 성공과 유효 표본

한눈에 요약

비퇴화 문항 수 neff는 비교 집합 안에서 일부만 해결된 문항 수다. 상위 10개에서는 neff/n=0.33, 상위 2개에서는 0.07이다.

상위 10개가 공통으로 푼 285개와 모두 실패한 51개는 점수에는 들어가지만 순위 구분에는 기여하지 않는다. 해답 집합 nesting도 frontier에서 0.935로 score-implied baseline 0.774보다 높아, 시스템이 서로 보완하기보다 비슷한 문제를 푼다.

03Attribution · 귀속

모델과 scaffold

한눈에 요약

한 점수는 모델만이 아니라 agent loop·도구·검색·제어정책을 포함한 scaffold와 모델의 쌍이다. 같은 모델에서도 scaffold 범위가 최대 29.8%p였다.

claude-3-5-sonnet은 아홉 scaffold에서 168–317개를 기록했다. 연결된 cell fit은 R²=0.989였지만 인과 효과는 아니다. 상호작용 검정은 scaffold 순서가 모델에 따라 뒤집힐 수 있음을 보였다.

초등학생도 이해하는 설명

같은 선수라도 코치와 장비가 바뀌면 기록이 달라진다. 모델 이름만 적은 리더보드는 코치 정보를 빠뜨린 기록표다.

04Tiers · 등급

05Limits · 한계

한계와 재현성

한눈에 요약

SWE-bench 계열과 공개 제출만 분석하며 모델 실행 변동·scaffold의 인과 효과를 식별하지 않는다. 비기각은 동등성 증명이 아니다.

재현성 패키지는 verdict·metadata·스크립트·seed·input hash를 포함한다. 다만 submission provenance가 불완전하고 다른 benchmark에서의 외부 검증은 남아 있다.

＋Glossary · 핵심 용어

핵심 용어 정리

neffeffective comparison size

비교 집합에서 일부만 해결된 비퇴화 문항 수.

nesting coefficient해답 포섭률

약한 시스템의 성공 중 강한 시스템도 성공한 비율.

scaffold실행 골격

도구·검색·루프·제어정책을 포함한 모델 바깥 구성.

McNemar testpaired 검정

같은 문항에서 A만 맞힌 수와 B만 맞힌 수를 비교.

Holm correction다중검정 보정

여러 p-value의 거짓 양성을 줄이는 절차.
