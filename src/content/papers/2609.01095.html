01Problem · 문제

과학 코드는 문법보다 소프트웨어 관계에서 무너진다

한눈에 요약

LLM은 얼핏 그럴듯한 ROOT 코드를 쓰지만, 없는 메서드·낡은 오버로드·누락된 의존성 때문에 실행에서 깨진다. 논문은 이 문제를 더 큰 모델이 아니라 사전에 정리한 소프트웨어 지식으로 풀려고 한다.

대상은 실험 고에너지물리에서 널리 쓰는 C++ 프레임워크 ROOT다.

평가 요청 275개는 ROOT 튜토리얼 구현을 프레임워크 클래스나 API 이름 없는 자연어 요구사항으로 바꿀 것이다. 참조 구현은 생성 중에는 보이지 않고 마지막 독립 평가에만 쓰였다.

02Method · 방법

구조, 완성된 예제, 실행 오류를 서로 다른 근거로 쓴다

한눈에 요약

구조 그라운딩은 코드베이스의 contains·depends·extends 관계를, 절차 그라운딩은 완성된 ROOT 튜토리얼을, 진단 그라운딩은 실행 로그와 관련 그래프 노드를 사용한다.

그래프는 49,270개 노드와 167,472개 방향 간선을 갖고, 32,603개 노드만 1,024차원 밀집 인덱스에 들어간다.

의미 쿼리는 dense 검색, API 쿼리는 BM25에 사용하고 RRF로 합친 뒤 재랭킹한다. 앵커에서 아무 두 합성 경로나 타는 것이 아니라 노드 타입별로 허용된 관계 순서만 최대 길이 2까지 확장한다.

03Results · 결과

첫 실행부터 최종 성공까지 두 오케스트레이션에서 모두 개선됐다

한눈에 요약

Claude Code에서 1차 실행률은 58.5%→76.0%, 독립 러너에서는 51.3%→64.0%로 올랐다. 최대 5회 수리 후 최종 성공률도 90.5%→96.0%, 78.9%→90.9%로 높아졌다.

라운드 0에서는 아직 실행 로그가 없으므로, 이 때의 차이는 구조·절차 컨텍스트가 만든 것으로 해석할 수 있다.

04Trade-offs · 비용과 수리

토큰은 더 많이 쓰지만, 성공 1건당 생성 비용은 거의 같다

한눈에 요약

그라운딩은 과제당 토큰을 Claude Code에서 65.9%, standalone에서 111.5% 더 썼다. 그러나 성공 수가 늘고 평균 수리 횟수가 줄어 성공 1건당 관찰 비용 차이는 +1.3%, +3.2%에 머물렀다.

최종 실패는 Claude Code에서 26건→11건, standalone에서 58건→25건으로 줄었다.

직접 생성 실패를 그라운딩이 구한 케이스는 각각 21건과 41건이고, 반대로 성공을 실패로 바꾼 케이스는 6건과 8건이었다. Error-RAG는 동일한 1차 실패에서 원시 로그만 넘기는 수리보다 18.6%p 높은 수리 성공률을 냈다.

05Validity · 재현성과 한계

결과는 ROOT에서 강하지만, 일반 코드베이스로의 전이는 아직 가설이다

한눈에 요약

연구는 오픈소스 ROOT 저장소와 275개 과제, 두 오케스트레이션에서 재현 가능성을 높였다. 하지만 다른 프레임워크나 사내 코드에서 같은 수치가 나온다는 증거는 아니다.

생성에는 deepseek-v4-pro, 선택·판정에는 deepseek-v4-flash를 쓰었으므로 다른 모델 구성의 재현성도 별도로 보아야 한다.

또한 grounded Claude Code는 미리 계산한 컨텍스트를 한 턴에 넘기고 도구를 끄는 반면, direct는 최대 12 agent turns을 사용하므로 오케스트레이션 세부 조건은 완전히 동일하지 않다. 논문은 환경 차단 케이스를 별도로 유지하고, 구제·회귀 사례까지 공개해 이 경계를 보완한다.

재현 자료

ROOTER 소스코드는 논문에 명시된 GitHub 저장소에 공개돼 있다. 표 I에 기록되지 않은 ROOT 커밋·컴파일러·OS·하드웨어는 추정하지 않았다.

＋Glossary · 핵심 용어

핵심 용어 정리

한눈에 요약

논문의 주장을 따라가는 데 필요한 용어만 간결하게 모았다.

구조 그라운딩Structural grounding

코드베이스의 파일·클래스·패키지와 의존·포함·상속 관계를 생성 컨텍스트로 제공하는 방식.

절차 그라운딩Procedural grounding

개별 API가 아니라 여러 API를 합쳐 완성한 공식 튜토리얼 예제를 제공하는 방식.

진단 그라운딩Diagnostic grounding

실행 오류와 관련 그래프 노드를 수리 단계에 제공하는 방식.

RRFReciprocal Rank Fusion

dense와 BM25처럼 다른 순위 목록을 각 순위의 역수로 합치는 방법.

품질 게이트Quality gate

종료 코드 0뿐 아니라 로그에 수치 오류·피팅 실패·출력 누락이 없는지 확인하는 판정기.

Error-RAGExecution-feedback RAG

실패한 코드를 직접 수정할지, 그래프 노드를 검색할지, 환경 문제로 중단할지 고르는 루프.
