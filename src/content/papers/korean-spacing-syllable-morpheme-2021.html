01Data · 띄어쓰기와 말뭉치

띄어쓰기는 보기 좋은 형식이 아니라 의미를 가르는 경계다

한눈에 요약

“아버지가 방에 들어가신다”와 “아버지 가방에 들어가신다”처럼 공백 하나가 구조와 의미를 바꾼다.

세종 문어 말뭉치와 뉴스 기사를 정제하고, 6~13어절 길이로 재구성해 약 1,300만 문장을 학습에 사용했다.

논문은 문장을 음절·형태소·어절의 세 층으로 본다. 음절과 형태소는 입력 특징이고, 실제 띄어쓰기 단위인 어절은 평가 단위다.

검색 시스템에 주는 힌트

검색 전에 완벽한 띄어쓰기 복원기를 반드시 두어야 한다는 뜻은 아니다. 오히려 공백 비의존 문자 n-gram 검색을 기본 안전망으로 두고, 품질이 더 필요한 경우 띄어쓰기 복원 또는 형태소 필드를 추가하는 계층형 설계가 자연스럽다.

04Limitations · 적용 범위

높은 점수의 바깥: 뉴스형 데이터와 형태소 분석 의존성

한눈에 요약

훈련 데이터는 세종 문어와 뉴스가 중심이라 커뮤니티 신조어·구어 축약·오타에 같은 성능을 보장하지 않는다.

형태소 입력을 만들려면 결국 형태소 분석기가 필요하므로, “분석기 없이 검색”이라는 목표에는 음절 모델이나 문자 n-gram이 더 직접적이다.

논문은 띄어쓰기 교정 자체의 점수는 잘 보여주지만, 교정 전후에 실제 검색·분류 성능이 얼마나 변하는지는 후속 과제로 남긴다.

주의할 점

저자들은 수집된 문장의 띄어쓰기가 대체로 옳다고 가정해 정답 태그를 만들었다. 뉴스와 세종 말뭉치의 규범성이 실제 사용자 질의의 오타·붙여쓰기·신조어 분포와 다를 수 있다.

따라서 사용자 검색어 처리에서는 이 모델 하나로 모든 변형을 고치기보다, 원문 보존 + 정규화 필드 + 공백 제거 음절 bigram + 선택적 교정을 함께 평가하는 편이 안전하다.
