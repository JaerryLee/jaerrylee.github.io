01Problem · 문제

과학 질문은 정답 근거가 여러 논문에 흩어져 있을 수 있다

한눈에 요약

LitTraceQA는 질문에 답하는 논문을 찾고, 논문 안의 근거를 짚고, 여러 논문의 사실을 합쳐야 한다. 질문에 직접 비슷한 논문만 찾으면 연결은 약하지만 중요한 논문을 놓칠 수 있다.

Lit3R은 검색(Retrieve), 논문 관계 확장(Rel​​ate), 근거 읽기(Read)를 차례로 묶은 훈련 없는 시스템이다.

팀은 55개 검증 질문만 있는 제한된 환경에서 공개 검색·재순위화·LLM 부품을 조합했고, 공식 테스트 순위 4위를 기록했다.

초등학생도 이해하는 설명

처음 질문으로 책을 찾고, 그 책이 가리키는 다른 책도 찾아본 다음, 실제 답이 적힌 문장을 확인한다.

그래프 계열 판독

이 논문은 Microsoft GraphRAG처럼 문서 청크에서 엔티티·관계 그래프와 커뮤니티 보고서를 만드는 방식이 아니다. 논문 간 관계를 이용해 후보 순위를 확장하는 “paper-to-paper retrieval”이다.

02Retrieve · 질문으로 찾기

질문을 여러 하위 질문으로 쪼개 sparse와 dense 검색을 함께 쓴다

한눈에 요약

첫 단계에서 LLM이 질문을 검색 가능한 하위 질문으로 나눈다. 각 하위 질의마다 BM25 어휘 검색과 임베딩 기반 dense 검색을 합치고, 재랭커가 청크 순서를 다시 정한다. 검증기가 근거가 부족하다고 하면 필요한 내용 중심의 하위 질의를 더 만든다.

검색 목록은 Reciprocal Rank Fusion으로 합치고, 총 50개 논문 후보를 다음 단계에 넘긴다.

BM25는 같은 단어를 포함한 문서를 잘 찾고 dense 검색은 뜻이 비슷한 표현을 찾는다. 둘을 합치면 어휘가 다르지만 의미가 맞는 논문과 이름이 직접 맞는 논문을 함께 건질 가능성이 있다.

03Relate · 논문 간 확장

처음 찾은 논문과 연결된 논문을 한 번 더 따라간다

한눈에 요약

검색 1위 논문에서 의미·서지정보·어휘가 연결된 다른 논문을 찾아 별도의 Ranking B를 만든다. 질문과 직접 비슷하지 않은 논문이더라도 논문 간 연결을 통해 후보로 회수될 수 있다.

다중 논문 질문에서 Ranking A만 쓴 경우 recall@50은 .647, 관계 확장을 더하면 .940으로 올랐다.

이것은 “그래프 추론이 답을 풀었다”는 실험이 아니라, 논문 간 관계 확장이 관련 후보를 더 많이 회수했다는 실험이다. 최종 목록은 A와 B 순위를 합쳐 정한다.

04Read · 근거 읽기와 답 생성

논문을 찾는 점수와 근거를 제대로 짚는 점수는 다르다

한눈에 요약

상위 후보를 논문별로 읽어 실제 답 근거가 있는 논문만 남기고, 그 뒤 여러 논문에서 사실·단위·출처를 모아 답을 합성한다. 답에는 논문 ID와 근거 위치를 붙인다.

공식 테스트에서 논문 검색 F1은 .992였지만, 근거 연결 F1은 .737, 표 셀 정확도는 .309였다.

즉 논문을 놓치지 않는 것과 그 논문 안의 정확한 문장을 골라 수치나 표로 답을 만드는 것은 다른 어려움이다. 이 차이는 검색 시스템 평가에서 recall@k만 보지 말고 근거 추출과 답 형식도 따로 측정해야 함을 보여준다.

05Limits · 해석 경계

높은 논문 recall이 완성된 연구 조수의 성능을 뜻하진 않는다

한눈에 요약

검증 질문이 55개뿐이고, 이 같은 검증 데이터로 구성·하이퍼파라미터를 선택했다. 공개 테스트에서 4위였지만, 다른 분야·질문 유형의 일반화와 독자 단계별 기여는 분리해 시험하지 않았다.

또한 “관계 확장”은 지식 그래프 데이터베이스나 Microsoft GraphRAG와 동의어가 아니다.

이 시스템의 점수 상승은 paper-to-paper 후보 순위 확장의 이득이다. 본문 안의 엔티티·사실 지식 그래프를 만들거나 그래프 커뮤니티 요약으로 답을 생성한다는 주장은 아니다. 구현 재현에는 Azure GPT-5.4와 MinerU 3.4.3 계열 설정도 영향을 준다.

＋Glossary · 핵심 용어

핵심 용어 정리

한눈에 요약

논문의 주장을 따라가는 데 필요한 용어만 간결하게 모았다.

희소 검색Sparse retrieval

BM25처럼 질문에 나온 단어가 문서에 얼마나 잘 나타나는지로 찾는 방식.

Dense 검색Dense retrieval

질문과 문서를 임베딩 벡터로 바꾸고 의미가 가까운 것을 찾는 방식.

RRFReciprocal Rank Fusion

여러 순위 목록에서 각 문서의 순위를 합쳐 하나의 후보 순위를 만드는 방식.

재랭커Reranker

검색된 후보들을 더 강한 모델로 다시 점수화해 순서를 조정하는 단계.

후보 회수율Candidate recall

정답 근거 문서 가운데 검색 후보 목록에 들어온 비율.

근거 정렬Evidence grounding

답의 주장을 실제 원문 문장·표·위치와 연결하는 것.
