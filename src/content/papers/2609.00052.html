01Threat model · 문제

API의 모델 이름과 실제 백본이 같은지 텍스트 없이 감사한다

한눈에 요약

에이전트형 API는 자연어 답변을 버리고 구조화된 도구 호출만 노출할 수 있다. 기존 모델 신원 감사는 텍스트 토큰에 의존하므로 이 환경에서는 취약하다.

서빙 사업자는 비용 절감을 위해 광고한 모델을 더 싼 모델, 양자화 변형, 라우터로 바꿀 수 있다.

반대로 정상 사업자가 숨겨진 시스템 프롬프트를 추가한 것만으로 텍스트 분포가 바뀌어 기존 감사가 오탐을 낼 수 있다. AgentProv는 후학습으로 가중치에 내재화된 도구 선택 분포를 대신 피거프린트로 사용한다.

02Method · 행동 프로브

동일한 기능의 도구 여러 개를 보여주고 선택 편향을 분포로 만든다

한눈에 요약

각 템플릿은 메일·캘린더처럼 같은 작업을 하는 복수의 도구를 제시한다. 모델이 고른 도구, 호출 없음, 형식 오류까지 모두 버킷에 넣어 원-핫 행렬로 바꾼다.

주 설정은 20개 템플릿에서 각 50번, 엔드포인트당 1,000회 질의다.

참조와 의심 엔드포인트의 블록별 행동 평균 백터를 만들고 제곱 L2 거리, 즉 델타 커널의 MMD²를 검정통계량으로 쓴다. 라벨을 같은 템플릿 안에서만 1,000번 섞어 유의수준 0.05의 정확한 순열 p값을 계산한다.

03Controlled evaluation · 통제 평가

36개 체크포인트의 630개 다른 쌍을 모두 탐지했다

한눈에 요약

오픈 체크포인트 36개의 다른 모델 쌍 630개를 100% 거부했고, 같은 모델의 독립 표본 36개는 모두 수용했다. 9개 OpenAI 모델도 9개 자기 비교를 모두 수용하고 36개 교차 비교를 모두 거부했다.

패밀리 내 거리는 패밀리 간 거리보다 대체로 1.8–3.0배 작았다.

예외는 서로 다른 베이스에 Hermes SFT를 적용한 경우다. 이들은 Hermes 동료보다 자신의 베이스에 더 가까웠다. 반대로 Qwen3 thinking 후학습은 같은 베이스의 다른 Qwen3보다 약 14배 멀리 이동해 행동 정책이 후학습에 민감함을 보였다.

04Deployment · 실제 API와 회피

텍스트 감사는 숨겨진 프롬프트를 모델 교체로 오인하기 쉽다

한눈에 요약

가중치는 같고 시스템 메시지만 바꾼 15개 통제 실험에서 MET는 10/15, RUT는 8/15, 적응한 LLMmap은 3/15를 잘못 거부했다. AgentProv의 오탐은 1/15였다.

OpenRouter 9개 엔드포인트에서 AgentProv는 7개를 수용했지만 MET는 1개, RUT는 2개만 수용했다.

이 엔드포인트의 진짜 백본은 공개되지 않았다. 저자들은 공급자가 보고한 prompt token 수와 로컬 챗 템플릿 계산값의 항상적 양의 차이를 숨겨진 프롬프트 사이드채널로 써 결과를 해석했다. 그러므로 실제 API 결과는 인과적 진실판정이 아니라 상관 근거다.

05Appendix & limits · 부록과 한계

AgentProv는 신뢰할 수 있는 참조가 있어야 하며, 완전한 신원 증명서가 아니다

한눈에 요약

검정이 보여주는 것은 프로브 상의 도구 선택 분포가 다르다는 사실이지, 서빙 가중치가 정확히 무엇인지는 아니다. 신뢰할 참조 API나 로컬 체크포인트가 없는 완전 폐쇄형 모델에는 적용할 수 없다.

정품 모델과 프로브별 분포까지 알고 프로브를 정확히 식별하는 적응적 서빙자는 재연을 할 수 있다.

저자들은 비공개 프로브 집합을 순환시켜 이 요구를 높이라고 제안한다. 8비트 양자화는 수용했지만 4비트는 모델별로 결과가 달랐고, 에이전트 래퍼 프롬프트는 AgentProv에서도 2/6 오탐을 만들었다.

핵심 용어 정리

논문의 주장을 따라가는 데 필요한 용어만 간결하게 모았다.

행동 정책Action policy

주어진 상태에서 각 도구 호출을 선택할 확률 분포.

프로브Probe

동일한 기능의 도구 여러 개와 중립적 요청으로 구성한 감사 테스트 상황.

MMDMaximum Mean Discrepancy

두 표본 분포가 같은지 커널 공간에서 비교하는 이표본 검정 통계량.

순열 검정Permutation test

참조와 의심 라벨을 동일 템플릿 안에서 섞어 귀무분포를 만드는 검정.

오탐False positive

실제 모델이 같은데도 다르다고 판정하는 오류.

숨겨진 프롬프트Hidden system prompt

API 공급자가 사용자에게 보이지 않게 추가하는 시스템 메시지.
