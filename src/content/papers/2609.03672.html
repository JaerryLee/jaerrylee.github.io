01Definition · 정의

convolution sum-product query는 무엇인가

한눈에 요약

CSPQ는 관계 원자의 인자를 변수 하나가 아니라 선형 결합 벡터로 표현한다. 그래서 A(X)·B(Y−X,Z−Y)·C(Z) 같은 convolution·3SUM·행렬 연산을 같은 질의 형식으로 다룬다.

기존 sum-product query는 변수와 관계의 위치를 분리해 썼지만, CSPQ는 각 원자의 인자를 벡터 묶음으로 보고 span(Q)를 질의가 실제로 사용하는 선형 공간으로 정의한다. head 벡터가 span 안에 있어야 하는 safety 조건은 전통 CQ의 “head 변수는 body에 등장해야 한다”와 같은 역할을 한다.

초등학생도 이해하는 설명

A에서 숫자를 하나 고르고 B와 C에서 맞는 조합을 찾은 뒤, 같은 출력 칸에 값을 더해 주는 질의다.

02Semantics · 의미

무한히 세지 않도록 active space를 quotient한다

한눈에 요약

R(X+Y)처럼 변수 두 개가 하나의 선형식으로만 관측되는 질의를 모든 (X,Y)에 대해 합하면 같은 tuple을 무한히 세게 된다. CSPQ는 null space를 quotient한 active space에서 한 번씩만 합산해 의미를 유한하게 만든다.

관계 원자의 벡터에 모두 직교하는 방향은 어떤 원자 값도 바꾸지 않으므로 관측되지 않는 null space다. 이를 제거하면 서로 같은 관계 조합을 만드는 valuation이 하나의 equivalence class가 되고, 정의 3.2의 합은 유한 support를 가진다. 변수 치환 Lemma 3.8은 span 위의 injective linear substitution이 질의 답을 보존함을 보인다.

초등학생도 이해하는 설명

보이지 않는 방향으로 계속 움직인 사람을 여러 명으로 세지 않고, 실제로 다른 결과를 만드는 경우만 센다.

03Algorithms · 알고리즘

dense·sparse·join·tree decomposition을 결합한다

한눈에 요약

dense 데이터에는 active-domain 크기 지수 알고리즘, sparse 데이터에는 fractional edge cover 기반 worst-case optimal join을 사용한다. 이후 convolution tree decomposition(CTD)으로 질의를 factorize해 메시지를 전달한다.

Dense Evaluation은 k=dim(span(Q))일 때 O(|adom(D)|ᵏ)이다. CSPQ용 fractional edge cover는 여러 atom의 span 교집합을 가중치 합으로 덮는 정의로 확장되며, 전통 CQ에서는 고전 정의로 되돌아간다. CTD는 각 bag의 선형 공간을 message query로 만들어, child 결과를 parent의 basis로 전달한다.

핵심 결론

선형식을 predicate로 취급하면 일반 제약 처리의 손해를 보지 않고 join 알고리즘과 factorization을 재사용할 수 있다.

초등학생도 이해하는 설명

큰 표를 전부 조인하지 않고, 필요한 부분 결과를 작은 봉투로 접어 위로 전달하는 방식이다.

04Width · width

ctw·atw·fcw가 서로 다른 비용 축을 잡는다

한눈에 요약

ctw는 bag의 선형 공간 차원, atw는 그 bag을 덮는 body vector 수, fcw는 fractional cover 비용을 잰다. 각각 값의 최대 크기·active domain·관계 튜플 수에 맞는 실행 시간을 준다.

정수 domain이면 convolution treewidth에 대해 O(n(D)^(ctw+1)), active treewidth에 대해 O(|adom(D)|^(atw+1)), fractional convolution hypertree width에 대해 O(|D|^fcw) 알고리즘을 제시한다. 전통 conjunctive query에서는 ctw=atw가 treewidth와 같고 fcw는 fractional hypertree width와 일치한다. (k+1)-SUM 예에서는 적절한 reduct와 CTD로 O(n^ceil((k+1)/2))를 얻는다.

초등학생도 이해하는 설명

같은 지도라도 도시 크기, 주소 개수, 실제 사람 수 중 무엇을 세느냐에 따라 가장 좋은 길이 달라진다.

05Extensions · 확장

임의의 field와 향후 최적화

한눈에 요약

CSPQ의 대부분 정리와 알고리즘은 rational 대신 임의의 field에서도 성립한다. positive characteristic field에서는 가장 작은 subfield 크기 n(D,Q)를 써 ctw 기반 상한을 다시 쓸 수 있다.

논문은 exact-weight subgraph와 functional dependency를 더 잘 다루려면 width 정의에 추가 구조가 필요하다고 말한다. 향후에는 FFT·빠른 행렬 곱, (#)-submodular width, 비선형 표현·group domain으로 확장하는 방향이 남아 있다.

한 줄 결론

CSPQ는 선형 표현을 질의 계획의 중심으로 가져오고, 데이터의 밀도와 표현 공간에 맞는 실행 폭을 선택하게 한다.

초등학생도 이해하는 설명

도시마다 도로망을 똑같이 깔지 않고, 인구와 지형을 보고 다른 길찾기 알고리즘을 고르는 셈이다.
