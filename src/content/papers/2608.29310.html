01Problem · 문제

LLM 코딩 에이전트가 관련 앱을 독립적으로 만들면 공통 로직을 매번 다시 쓰고, 변경도 앱마다 반복해야 한다.

한눈에 요약

LLM 코딩 에이전트가 관련 앱을 독립적으로 만들면 공통 로직을 매번 다시 쓰고, 변경도 앱마다 반복해야 한다.

논문은 앱 요청의 시퀀스를 처리하면서 공통 Super Library와 이전 앱을 함께 갱신하는 온라인 문제를 새로 정의한다.

이상적인 라이브러리는 최소 두 앱에서 쓰이는 컴포넌트를 담고, 앱 전용 코드는 로컬에 남긴다. 목표는 최종 앱 기능성과 전체 포트폴리오 유지보수성의 Pareto 균형이다.

02Method · 방법

단순 에이전트는 재사용 후보를 놓치고 추출 후 의존성까지 안전하게 바꾸지 못한다. SLA-FULL은 발견과 이주를 분리하고 구조화된 증거를 전달한다.

한눈에 요약

단순 에이전트는 재사용 후보를 놓치고 추출 후 의존성까지 안전하게 바꾸지 못한다. SLA-FULL은 발견과 이주를 분리하고 구조화된 증거를 전달한다.

AST 단위 코드 블록을 자연어로 요약해 “어떻게 생겼는가”가 아니라 “무엇을 하는가”로 후보를 찾는다.

추출 에이전트는 출처 블록·일반화 이유·교체 API를 extraction trace로 남긴다. 이주 에이전트는 관련 import, caller, callee를 담은 also-refactor 목록을 받아 호출부와 죽은 코드를 함께 수정한다. 신규 코드베이스 내부의 중복도 먼저 한 번 통합한다.

WebGen-Bench와 PaperBench 모두에서 기능은 유지하면서 코드 크기와 중복 지표가 개선됐다.

한눈에 요약

04Analysis · 재사용의 질

SLA-FULL은 단순 UI 조각뿐 아니라 상태·동작 훅과 페이지/도메인 패턴을 더 많이 재사용했다.

한눈에 요약

SLA-FULL은 단순 UI 조각뿐 아니라 상태·동작 훅과 페이지/도메인 패턴을 더 많이 재사용했다.

평균 export는 13.3개였고, 3–5개 앱에서 쓰인 심볼 6.0개, 6–8개 앱에서 쓰인 심볼 4.8개로 naive 변형보다 많았다.

완성 라이브러리를 신규 앱 생성의 prior로만 제공한 실험에서도 정확도는 80.95%에서 84.35%로 오르고 전체 LOC는 약 11% 줄었다. 호출 그래프 제거 시 정확도와 구조 지표가 나빠져 안전한 의존성 갱신의 중요성이 드러났다.

05Appendix · 비용과 한계

공유 라이브러리는 유지보수를 줄이지만 초기 생성 비용은 늘고, 벤치마크는 실제 장기 포트폴리오를 충분히 대변하지 못한다.

한눈에 요약

공유 라이브러리는 유지보수를 줄이지만 초기 생성 비용은 늘고, 벤치마크는 실제 장기 포트폴리오를 충분히 대변하지 못한다.

SLA-FULL의 포트폴리오 생성 비용은 Zero-Shot의 8.3배였다. 세션 재사용과 라운드 수 감소로 비용을 줄일 수 있지만, 라운드를 4회에서 1회로 줄이면 정확도·LOC·verbosity가 악화됐다.

N=16 저재사용 스트레스 테스트에서 SLA-FULL은 LOC·토큰·verbosity는 최저였지만 정확도는 Zero-Shot보다 낮았다. 저자들은 실제 사용자·커밋 이력이 없는 생성 벤치마크, 단 한 번의 유지보수 라운드, proxy 유지보수 지표, 공유 라이브러리 오류의 확산 위험을 한계로 적는다.

핵심 용어 정리

한눈에 요약

논문의 주장을 따라가는 데 필요한 용어만 간결하게 모았다.

Super LibraryShared library

서로 독립 배포되는 관련 앱들이 함께 가져다 쓰는 공통 컴포넌트 저장소.

추출 흔적Extraction trace

공통 심볼의 출처, 일반화 이유, 대체 방법을 이주 에이전트에 넘기는 구조화 기록.

호출 그래프 조건화Call-graph conditioning

교체 대상의 import와 caller/callee를 함께 보여줘 비국소 수정 누락을 줄이는 방법.

구조적 침식Structural erosion

복잡도가 높은 함수에 코드 복잡성이 얼마나 몰려 있는지 나타내는 유지보수 proxy.

MDLMinimum Description Length

참조 모델이 전체 코드를 설명하는 데 필요한 음의 로그확률 기반 크기 지표.
