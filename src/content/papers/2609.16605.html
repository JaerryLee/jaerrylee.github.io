01Motivation · 동기

공급망 위험과 연구 질문

한눈에 요약

악성 package가 정상 업데이트처럼 퍼지면 탐지 시간이 없다. GitHub는 2025년 7월 cooldown을 GA로 제공했고, 논문은 인기 저장소의 도입·중단·설정을 탐색한다.

보안 동기가 알려진 92건 중 83건이 security concern과 연결됐고, security-only 도입 75건 중 43건은 linter warning에서 시작됐다.

초등학생도 이해하는 설명

업데이트를 며칠 늦추면 확인할 시간은 생기지만 모든 package를 똑같이 늦추면 문제가 된다.

05Configuration · 설정

설정과 한계

한눈에 요약

251개 retained ecosystem 중 default-days는 97.2%, 최빈값은 7일이었다. include/exclude는 각각 1.2%, 2.0%로 드물었다.

설정 변경은 적었고 3·4일에서 7일로 올리는 사례가 보였다. 인기 GitHub 저장소만 대상으로 하며 third-party auto-merge를 놓칠 수 있고 효과 자체를 검증한 연구는 아니다.
